# Koura

Tema para [Obsidian](https://obsidian.md) con sombras neumórficas, esquinas
suaves y un tono de acento configurable. Funciona en claro y en oscuro.

## Instalación

1. Descarga el repositorio (**Code → Download ZIP**) y descomprímelo.
2. Copia `theme.css` y `manifest.json` a `.obsidian/themes/Koura/` dentro de
   tu vault (crea la carpeta si no existe).
3. Abre Obsidian y ve a **Ajustes → Apariencia → Tema**; elige **Koura**.

No hay que compilar nada: Obsidian lee `theme.css` y `manifest.json` de esa
carpeta.

## Contenido

| Fichero | Para qué sirve |
| --- | --- |
| `theme.css` | El tema completo (claro y oscuro). |
| `manifest.json` | Nombre, versión y versión mínima de Obsidian (`1.0.0`). |

## Notas

- El tema incluye un bloque `.disabled` con una imagen de fondo de Unsplash.
  Está desactivado a propósito: si quieres usarlo, quita o renombra ese
  selector. Al estar enlazada desde el CSS, esa imagen necesita conexión.
- Los snippets que uso junto al tema (`folder-colors`, `tasks_style`,
  `daily-nav`…) no forman parte del tema y no se instalan con esta carpeta.
